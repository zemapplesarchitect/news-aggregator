### Developer Tools &amp; Open Source Frameworks

**Google Releases LiteRT.js for High-Performance In-Browser AI**
Google has released LiteRT.js, a JavaScript binding that allows developers to run .tflite models directly in the browser using WebGPU for hardware acceleration. The new runtime promises significant performance gains (up to 60x on GPU/NPU) over other web-based inference solutions, enabling more powerful on-device AI. (Source: MarkTechPost)

**Google and Partners Announce Agentic Resource Discovery (ARD) Specification**
Google, along with industry partners, has announced the Agentic Resource Discovery (ARD) specification, an open standard for AI agents to discover, verify, and use tools and APIs. The standard aims to create an interoperable ecosystem where agents can dynamically find and leverage new capabilities in a trusted manner. (Source: InfoQ - AI, ML &amp; Data Engineering)

**Stanford's TRACE System Trains AI Agents on Their Own Failures**
Stanford researchers have introduced TRACE, a training system that diagnoses recurrent failures in AI agents and synthesizes targeted reinforcement learning environments to teach them specific skills. This approach significantly improved performance on coding benchmarks like SWE-bench, demonstrating a new path for creating more capable agents. (Source: MarkTechPost)

**PrismML Releases Bonsai 27B, a Highly Compressed Open Model**
PrismML has released Bonsai 27B, a 1-bit and ternary version of the Qwen3.6-27B model that can run on consumer devices like laptops and phones. By using extreme quantization, the model size is reduced to under 6GB while retaining much of its capability, making powerful AI more accessible. (Source: MarkTechPost)
